# 🎵 游戏口琴自动音乐弹奏脚本 (Harmonica Auto Player)

专为游戏中口琴、笛子、乐器演奏设计的自动弹奏工具。  
**已完整适配游戏原生演奏键位（匹配游戏 HUD 界面）：**
- 基础音阶：`1` ~ `7` 对应键盘 **`Z X C V B N M`**
- 额外高音：高音 1 (`1̇`) 专属按键对应键盘 **`,` (逗号键)**
- 升降调与半音动作：
  - 🖱️ **降调 (低八度)**：**鼠标左键**
  - 🖱️ **半音 (升半音)**：**鼠标中键 (滚轮按下)**
  - 🖱️ **升调 (高八度)**：**鼠标右键**

工具基于 **Windows 底层 DirectInput 硬件扫描码 (Scan Code) 与硬件级鼠标事件** 驱动模拟，支持按住升降调/半音的严格时序保护，能稳定穿透 DirectX / 3D 游戏的防脚本拦截，提供高精度节拍控制、全局热键后台响应与开箱即用的现代化图形界面。

| :---: | :---: | :---: | :---: |
| **1** | Do | **`Z`** | 基础中音 1 |
| **2** | Re | **`X`** | 基础中音 2 |
| **3** | Mi | **`C`** | 基础中音 3 |
| **4** | Fa | **`V`** | 基础中音 4 |
| **5** | Sol | **`B`** | 基础中音 5 |
| **6** | La | **`N`** | 基础中音 6 |
| **7** | Ti | **`M`** | 基础中音 7 |
| **1̇ (1')** | 高音 1 | **`,` (逗号键)** | 游戏专属单按高音 1 |

### 升调、降调与半音触发动作
| 类型 | 乐谱写法示例 | 触发动作 | 示例与时序说明 |
| :---: | :---: | :---: | :---: |
| **高音一级 (2'~7')** | `2'`, `3'`, `+2` | **鼠标右键(升调) + 音符键** | 弹 `2'` $\rightarrow$ 按住鼠标右键，敲击 `X` |
| **高音 1 (1')** | `1'`, `+1`, `1̇` | **单按 `,` (逗号)** | 优先单按专属键，极速无延迟 |
| **低音一级 (1.~7.)** | `1.`, `2.`, `-1` | **鼠标左键(降调) + 音符键** | 弹 `1.` $\rightarrow$ 按住鼠标左键，敲击 `Z` |
| **中音半音 (#1~#6)** | `#1`, `#4`, `b3` | **鼠标中键(半音) + 音符键** | 弹 `#4` $\rightarrow$ 按住鼠标中键，敲击 `V` |
| **高音半音 (#1'~#6')** | `#4'`, `#5'` | **鼠标右键 + 鼠标中键 + 音符键** | 升调与半音同按（高音升1可按中键+逗号） |
| **低音半音 (#1.~#6.)** | `#1.`, `#5.` | **鼠标左键 + 鼠标中键 + 音符键** | 降调与半音同按 |
| **休止符** | `0` | *(不执行动作)* | 停顿等待相应拍数 |

## 🚀 2. 快速使用

### 环境准备
克隆仓库后，安装所需 Python 依赖：
```bash
pip install -r requirements.txt
```

### 方式一：双击启动 (推荐)
直接双击运行目录下的 **`run.bat`** 即可打开图形化控制面板。

### 方式二：命令行启动 GUI
在当前目录下运行：
```powershell
python main.py
```

### 方式三：命令行直接弹奏或试听 (CLI 模式)
```powershell
# 查看所有内置曲目
python main.py --list

# 弹奏含半音和高低音的《名侦探柯南》，倒计时 3 秒后在游戏内触发
python main.py --play "名侦探柯南"

# 导入本地 MIDI 音乐文件直接弹奏
python main.py --play "test.mid"

# 使用 PC 蜂鸣器试听（无需切进游戏，验证真实音高和节拍）
python main.py --play "送别" --preview
```

## 🎮 3. 全局热键使用方法

工具支持**后台全局热键**（即使游戏处于前台全屏焦点状态，也能直接触发）：

- **`F8`**：**开始 / 暂停 / 继续播放**  
  在工具中选好曲谱后，直接切回游戏、拿出乐器，在键盘上按下 `F8` 即可瞬间开始弹奏！再次按 `F8` 可暂停。
- **`F9`**：**停止播放**  
  随时按 `F9` 立即中断当前弹奏，并自动释放所有按键与鼠标按键。
- **`Esc`**：**紧急中止**。

## 🎼 4. 简谱记法与自定义曲谱编写

文本框支持非常直观好写的简谱格式：

1. **单音**：
   - 中音：`1 2 3 4 5 6 7`
   - 高音：`1' 2' 3'` 或 `1̇`（高音 1 自动使用逗号按键 `,`）
   - 低音：`1. 2. 3.` 或 `-1 -2 -3`
   - 升半音：`#1 #2 #4 #5 #6`
   - 降半音：`b2 b3 b5 b6 b7`（自动等音转为升半音）
2. **延音线 `-`**：
   - `1 -`：持续 2 拍
   - `1 - - -`：持续 4 拍
3. **休止符 `0`**：停顿 1 拍；`0 -` 停顿 2 拍。
4. **附点 `.`**：延长当前音符时值的一半（如 `1'.`）。
5. **连音与快音 (半拍/十六分音符)**：
   - 括号平分：`(1 2)` 表示在 1 拍内平分这两个音（每个 0.5 拍）；`(6. 7.)` 每个 0.5 拍。
   - 分数时值：`1/2` 表示半拍，`1/4` 表示四分之一拍。
6. **和弦 (多音同时按下)**：
   - 用中括号包围，如 `[1 3 5 1']`（四音同响）。
7. **小节线 `|`**：自动忽略，仅作排版视觉分隔。
8. **注释 `#`**：行首 `#` 或 `//` 视为注释（不会误伤 `#4` 升音标记）。

### 乐谱示例片段：
```text
# 《名侦探柯南》主旋律片段 (含升半音 #4 与低音 6. 7.)
(6 7) | 1' (7 6) 7 (3 3) | 6 (5 4) 5 (1 1) |
4 (3 2) 3 (6. 7.) | 1 2 7. - |
(6 7) | 1' (7 6) 7 (3 3) | 6 (5 #4) 5 - |
3' 2' 1' 7 | 6 - - 0
```

## ⚙️ 5. 配置文件 `key_config.json` 说明

项目根目录生成的 `key_config.json` 默认已更新为你的游戏原生配置：

```json
{
    "modifiers": {
        "high_octave": "mouse_right",
        "low_octave": "mouse_left",
        "semitone": "mouse_middle"
    },
    "base_keys": {
        "1": "z",
        "2": "x",
        "3": "c",
        "4": "v",
        "5": "b",
        "6": "n",
        "7": "m",
        "1'": ","
    },
    "custom_overrides": {
        "1'": [","],
        "#1'": ["mouse_middle", ","]
    }
}
```

## ⚠️ 6. 游戏环境注意事项

1. **管理员权限提示**：  
   若游戏开启了反作弊系统或以管理员身份运行，请右键点击 `run.bat` 选择 **“以管理员身份运行”**。
2. **窗口模式推荐**：  
   建议将游戏设置为 **“无边框窗口化 (Borderless)”** 或 **“窗口化”**。
3. **按键保持时长 (Hold Time)**：  
   界面下方默认按键保持时间为 35ms，如果游戏偶有判定吞音，可适当微调为 40~55ms。
